# Smart Campus Lost & Found Portal

## Project Overview
Smart Campus Lost & Found is a web application designed to help college students report lost belongings and search for found items on campus.

## Features
- Report lost and found items
- Search items by name
- Filter reports by Lost or Found
- View item category and location
- Mark items as recovered
- Responsive campus-themed user interface

## Technology Stack
- React.js
- JavaScript / TypeScript, depending on the exported project
- CSS
- Vite or the framework configured by Lovable

## How to Run Locally
1. Install Node.js.
2. Clone this repository.
3. Open the project folder in a terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL displayed in the terminal.
